# 布局热点优化验证（2026-10-09）

原始基线为 `2ae6d2a`。本轮按查询索引、浮动子树缓存、局部节点引用、
取整发布与验证复用、Flex 基线裁剪的顺序实施，没有更改公开接口或节点输出顺序。
原始记录、各阶段程序及 SHA-256 在 `build/hotpaths-20261009/`。
本文记录第一轮结果；第 6–10 项的后续处理见 [后续优化验证](hotpath-remaining-optimization.md)。

## 实现与适用范围

1. 借用模式的完整快照使用惰性排序索引，宿主 ID 可以稀疏且无序。
   索引首次构建 O(n log n)、查询 O(log n)，输出位置不变时跨发布复用，
   不使用逐节点查询的宿主没有索引成本。直接遍历 `LayoutResult::nodes` 仍最直接。
2. 浮动子树摘要存于节点，查询深度也是缓存键。自有树修改和借用节点标脏均失效祖先摘要；
   借用拓扑变更继续要求 `invalidate()`。移除了每次计算重新创建的哈希表。
3. Block/Flex 的最终子节点处理合并重复 `get()`，没有加入跨 epoch 的子节点指针数组。
4. 取整发布在不可变子树身份、成功发布代次、累计逻辑/像素坐标、比例和原点一致时复制旧范围。
   逻辑与取整记录分开标识；完整数值检查成功后才允许按需模式跳过重复验证。
   完整数组的复制仍为 O(n)，这不是整次计算只处理修改节点的承诺。
5. Flex 基线查询保留所有必要行测量，只对选定项目执行最终布局。
   保留自动边距、主轴累计顺序、stretch、换行与反向排列。

## 测量口径

- Windows x64，Intel Core i7-11700K，MSVC 19.51.36257.0，Release `/O2 /Ob2 /MD`。
- 平衡电源方案，驱动及子进程固定 CPU 4。计时串行执行，未与本任务的构建或测试重叠。
- 优化前后使用同一份 `css_hotpaths.cpp`。3 轮 × 9 批，轮间交换程序执行顺序。
- 各阶段覆盖 100、1,000、10,000 个叶节点。默认读取三个根相对节点；
  lookup 另测全量读取，节点总数还包含根和最多 16 个分支。
- `cold` 不计建树/销毁，计首次布局和读取；`edit` 计单叶样式修改、计算和读取；
  `resize` 变化根约束；`same` 保持输入不变。非 cold 每批预热四次。
- 各阶段分别使用每批 12、8、24 次。取整小树另以每批 256 次复核；
  最终整体对照对所有场景使用 1,000 叶节点、每批 128 次。
- 计时前用最多 100 叶的同结构场景比较增量与整树失效后的全部 NodeLayout 字段，
  计时比较优化前后消费校验和。
  基准不是浏览器、绘制或真实文本测量的整页测试。
- 表中为批均值的中位数（µs）。探索性 95% 区间按轮次和批次重采样；
  区间跨 1 标为不确定，不证明等速。低于 1 µs 的数字不作速度结论。

取整复用需要保存坐标上下文，因此它以少量记录分配换取时间；
完整取整首次布局的分配从 49 增至 64 次，申请字节从 310,998 增至 311,518。
申请字节不等同于整个进程或树的驻留内存。
排序索引保留容量，浮动摘要给节点增加固定元数据，均不能当作零内存成本。

取整 `edit` 平均复用 780.83 个已发布节点；基线场景的 `layout_count` 从 383 降至 321。
`published_nodes_reused` 只统计发布数组的区间复制，不统计按需模式跳过的验证。

## 限制与保留项

- 输入完全不变时本来就会复用整份结果，取整优化没有重新优化这一条路径。
- 本基准 100 叶分成 16 组，每组不足 8 个后代，不触发小子树复用。
  首轮短批次曾出现取整回退，256 次长批次未复现；完整和按需模式均无法认定快慢。
- 本基准 10,000 叶的每个分支超过原有 512 节点片段缓存上限，取整局部更新和 resize
  没有明确改善。缓存覆盖范围限制仍保留，不能将 1,000 叶的收益外推到任意大树。
- 初版将借用索引直接写入公共查询函数时，自有树全量读取曾测得约 6% 回退。
  拆成独立辅助函数后，以每批 2,000 次复核及最终整体对照均无法区分快慢；
  保留 `final/` 和 `owned-lookup-recheck/` 记录，不把这一项计为收益。
- 第一轮没有修改叶数组存储、隐藏子树、LayoutBox 生命周期、
  Grid 诊断开关的失效范围或批量拓扑修改；后续验证单独记录。
- 没有改变 Taffy 0.14 的行为参照；本轮不是 CSS 规范覆盖扩展。
