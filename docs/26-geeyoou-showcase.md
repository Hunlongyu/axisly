# GeeyoouUI 完整 Showcase 接入

本示例复用上游完整的 19 页 Showcase，由 axisly 排列页面及容器，GeeyoouUI 继续提供
控件、绘制、输入、数据、主题与原生窗口。上游固定为
`4cadaf6479b663ce6633e59bfbac28332de495fc`。示例不进入 axisly 的安装导出，默认构建不下载依赖。

## 构建和运行

```powershell
./scripts/build-msvc.ps1 -Preset geeyoou-release
./build/geeyoou-release/bin/axisly_geeyoou_showcase.exe
```

需要 Windows、MSVC C++20、CMake、Ninja、Git 与 Python 3.10+。脚本通过带 `-prerelease`
的 vswhere 查找工具链。Debug 可使用 `geeyoou-debug`。首次构建下载固定版本的
GeeyoouUI、Blend2D 和 AsmJit；源代码与生成覆盖文件均保存在忽略的构建目录中。

```powershell
# 隐藏的真实 Win32 窗口：实际事件循环、窗口缩放、键盘输入、全部页面和渲染截图。
./build/geeyoou-release/bin/axisly_geeyoou_showcase.exe --smoke build/geeyoou-captures
# 同时检查 core、适配器和 GeeyoouUI 控件；Blend2D/AsmJit 不作 ASan 插桩。
./scripts/build-sanitizers.ps1 -Compiler MSVC -Geeyoou
```

正常启动显示完整窗口，关闭窗口后退出；`--smoke` 自动完成验收并退出。
CTest 已包含适配器场景和整套窗口检查；CI 新增 Windows GeeyoouUI 作业并保存截图与日志。

## 迁移范围

| 页面或区域 | 接入方式 |
| --- | --- |
| 主界面 | axisly 固定侧栏、固定标题行、弹性内容区；侧栏可滚动并自动显示当前页入口 |
| 概览 | 重写为卡片网格、双列介绍面板和跨列说明；真实标签换行；中英文文案 |
| 布局引擎 | 权重与 max、百分比、跨格、dense 自动放置、隐式行、自定义控件首基线、动态增删／隐藏／文字更新 |
| 图标、基础控件、输入、运维、七类表格、三维页面 | 原有 BoxLayout／GridLayout 调用经同形接口接入 axisly；保留原有控件与事件 |
| 窗口、主题、HMI、下拉选择、对话框 | 将页面直接子面板的设计边界转成网格轨道；列可增长，保留最小画布和设计行高；小窗口滚动查看 |
| 工艺图、表格单元格／虚拟化、3D 场景、标题栏控件 | 保留控件内部坐标和专业算法，axisly 分配其外部矩形 |

全部 19 个页面的内容根都采用 axisly；这不表示每个控件内部的手工绘制坐标都改成了网格。
固定设计页的内部表单仍保留上游摆放规则。上游概览页的旧功能清单已替换，避免继续显示
“没有布局引擎”的过时描述。

## 适配器规则

- `AxislyLayout` 派生自宿主 `Layout`。通过 `Widget::sizeHint()` 的原有入口测量，
  保留宿主的测量／排列重入保护。持有子项索引与不复用的布局内 ID，不长期持有子控件指针。
- 每个容器拥有 `GridCache` 和尺寸提示缓存。内容变化使相应容器与祖先版本失效；
  无关的嵌套容器复用测量结果。同一父容器内的直接叶子会重新收集尺寸提示，
  本实现不承诺一次文字更新只测量一个叶子，也不声称跨层复用来自 `GridTree`。
- Label 通过 `heightForWidth` 使用 Blend2D 真实文本路径；嵌套布局通过带宽度的尺寸探测
  计算高度。探测仍经过 Widget 的重入保护。GroupBox 在锁定宿主版本中左右各有 12 像素框架，
  只在受约束的测量阶段扣除；arrange 接收的 content 已扣除框架与 margins，不再重复扣减。
- 内容视口按可用宽度重新测量，预留宿主 12 像素滚动条位置。动画帧合并内容尺寸变化，
  更新滚动范围，解决滚动容器中间的普通 Widget 阻断直接重排的问题；演示启用 30 FPS 宿主动画钟。
- 1D 布局使用单行／单列网格。权重沿用 **axisly 的比例分配语义**，并非上游 BoxLayout
  的“先满足 preferred，再分余量”。显式 spacer 两边不额外添加默认间距，隐藏控件退出排列。
- 逐控件 max 在最终应用矩形时限制自身；共享列不会被其中一个控件的 max 限制。
  一维独占轨道可以使用该控件的 max 作为轨道上限并重分余量。空间不足时保留 min、报告溢出。
- 无确定容器宽度的尺寸提示不把百分比乘以巨大哨兵值，而采用内容测量；有限宽度下恢复真实百分比。
- 所有测量先完成，再应用矩形。每次宿主回调后检查存活、结构版本和样式版本；
  回调中销毁或替换布局时停止本次剩余应用，由宿主原有延迟销毁机制释放布局。
  这不表示可以撤销回调已经产生的 UI 副作用。
- 使用逻辑坐标测量，按真实窗口的 scaleFactor 对最终边缘取整；离屏测试可指定 1／1.25／1.5／2 倍。
  基线示例使用控件声明的基线，并不推断所有宿主文字控件的字体基线。

`prepare.py` 在构建目录生成版本检查过的覆盖文件，不修改下载目录或调用者的源代码副本：

1. `Widget::markLayoutDirty` 通知适配器失效，使文字、可见性等变化能清除缓存。
2. `Layout::invalidate` 通过 `invalidateSizeHint` 通知祖先，避免修改嵌套布局后祖先仍用旧测量。
3. 改写 Showcase 的布局类型引用、Shell、品牌和烟雾测试入口；概览和布局页面使用本地覆盖文件。

## 验证与边界

自动场景覆盖权重、逐项最大尺寸、溢出、spacer、显隐、嵌套缓存失效、真实文字换行、字体／主题、
百分比、跨格、基线、四种像素比例、视口约束与动态高度。另有 8 组回调场景，覆盖测量及排列期间
销毁宿主、替换布局、删除当前控件、重入测量，检查延迟释放队列归零。

整套 Showcase 在三组配置下遍历 19 页，共 57 次访问：1320×860 中文深色、1024×720 英文深色、
1600×1000 英文浅色。使用真实 Win32 窗口消息进行缩放、按钮键盘激活和输入框文字输入，
并检查动态增删／显隐、滚动、控件矩形和实际 axisly 计算路径；截图由同一控件树与 Canvas 渲染。

本机运行结果与截图保存在 [验收证据](host-validation/geeyoou-2026-09-28/README.md)。
本次原生窗口 DPI 为 100%；125%／150%／200% 是适配器坐标测试，**没有代替多显示器实机切换验收**。
窗口遍历也不等于完整人工测试了每一种表格编辑、弹窗组合或 3D 操作。此阶段交付可运行的完整演示
和明确范围内的自动验收，不提升为正式 1.0 或生产使用保证。
