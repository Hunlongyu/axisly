# Taffy 0.14 布局能力对齐：最终验收

P0–P5 计划已完成。实现为独立 C++20 CSS 布局管线；原生 `compute_grid`、
`GridCache`、`GridTree` 保持原有合法输入语义。生产库只依赖 STL。

API 映射和行为验收**，没有未解释的未支持或部分支持项。

尺寸查询、基线查询与完整几何各自缓存。Block 预解析盒、Flex 晚期包含块和
Grid 轨道贡献是独立阶段，避免以最终几何替代固有探测。
输出存储、定位尺寸、浮动区域、网格放置及轨道求解均由独立内部模块承担。
最后的 RTL 根坐标检查改用共用平移，保持边框盒和内容盒同步移动；
独立断言覆盖四种布局、尺寸变化及本地缓存片段回放。

## 性能与宿主

同输入测量中，合成 384 叶首次布局中位时间 7862.03→7176.93 µs，
申请次数 35859→21904，申请字节 9091511→5477342。
窗口内 C++ 峰值存活字节增加 3.66%；DirectWrite 首次增加 3.47%，
分支编辑增加 8.90%。这是记录在案的存储取舍；不宣称总进程内存下降。
时间仅代表本机观察，申请计数与测量工作量在各批次可复现。
[同输入原始性能记录](benchmarks/css-retained-upstream-2026-09-30/README.md)包含
9 批×20 帧、两种叶子规模、六种场景、两种后端、两种失效策略与二进制哈希。

真实宿主通过 19 页×3 配置及四类 CSS 页。程序移动到全部四台已连接显示器，
逐项确认 Windows DPI 与宿主比例相同；实际覆盖 96／120 DPI（100%／125%）。
另有 150%／200% 逻辑像素测试。真实字体、内容变化、换行、隐藏／显示及
具名网格／浮动／定位均通过，保存 16 张 CSS 截图。
[宿主原始记录](host-validation/geeyoou-parity-2026-09-30/README.md)说明基线回退和 DPI 边界。

155 组引擎／模式完成几何重放，4 组本库 12 层内容驱动深树触发默认测量预算。
该输入仅 29 节点，首次报告 100001 次测量尝试与 429882 次布局探测；
Taffy／Yoga 能完成。这暴露了深层尺寸传播与缓存的性能问题。
既有字段/API 覆盖和 6020 项验收保留，本次新增输入的限制不以旧验收通过数覆盖。
[三方完整报告](benchmarks/css-comparison-2026-09-30/README.md)保留耗时、失败输入和复现命令。

随后重构 Flex 的尺寸探测、交叉轴定尺寸和最终布局阶段，修正逐层内容空间，
并重构节点缓存、尺寸查询与溢出处理。默认工作量、深度和缓存预算保持不变。
上述深树首次布局降至 48 次测量，叶更新为 3 次测量，四种模式全部完成。
新增 4／12／24／48 层回归覆盖换行、缩放、叶更新和工作量；
阶段拆分同时修复 Debug／ASan 的 48 层调用栈溢出。

### 第二轮性能重构

第二轮性能重构将节点目录改为连续哈希槽，缓存改为整棵树共用的槽池，子树几何共享后在发布时展开，
纯平铺结果在独占时直接移交缓冲，
压缩长度与样式表示，并移除 Flex 分行和约束分配的临时数组。
同时新增表达式所有权、事务失败回滚、节点存储生命周期、缓存深度预算，
滚动条与 aspect-ratio 最大尺寸顺序，以及几何快照生命周期的回归测试。

最终 Release **383/383**、Debug **383/383**、ASan **382/382**、
Comparison Release **339/339** 和安装消费测试全部通过。
三种参考配置均通过 6020 项；18 个基准场景连同上轮版本共 **220 组**
逐帧几何对照通过，0 预算失败。
[第二轮性能报告](benchmarks/css-optimization-round2-2026-09-30/README.md)
记录同 CPU、交替顺序的前后采样、三方差距、内存取舍和完整源码摘要。
`Length`/`Style` 的对象布局改变，宿主需要重新编译。

### 接口与规范边界

接口接收类型化 C++ 样式；CSS 字符串解析、选择器、级联、DOM、文本塑形、
绘制、事件及滚动控件不在本库范围。对齐目标是 Taffy 0.14 布局能力，
测试通过不等于所有 CSS 规范或所有未来输入都已证明正确。

已观察的版本差异包含反向 Flex stretch 回退、小系数与 gap、
Grid 负锚点具名 span、calc 自动重复准入、Block 百分比 padding 元数据，
另有 XML 的 RTL 负半像素整数预期。均有独立数值／浏览器重放并单独记录，
没有改参考输入或隐去失败来取得通过。
[规范／WPT 索引](32-css-normative-case-index.md)逐项说明来源和两套结果。
超出 Taffy 0.14 的完整 CSS 规范目标继续作为独立计划维护。
