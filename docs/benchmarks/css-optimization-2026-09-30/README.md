# CSS 布局性能重构与复测（2026-09-30）

比较当前 `css::LayoutTree`、Taffy 0.14.0、Yoga 3.2.1。时间为每批平均每帧耗时的中位数，单位 µs，越小越好。

## 本次变化

- Flex 拆分为初始化、收集、测量、交叉轴定尺寸、最终布局、结果汇总六个阶段。尺寸探测只请求需要的数据，确定尺寸后执行最终子布局。
- 修正固有尺寸探测的内容空间：逐层扣除容器自己的 margin、padding、border，消除深树中不同宽度的重复测量。
- 尺寸查询返回 `Size`，明确尺寸和无测量回调的空叶跳过几何片段构造；明确 flex-basis 的项目按需测量内容。
- 节点持有持久布局、测量与盒模型缓存；本轮查询独立暂存，成功后提交。递归期间不按节点条目数淘汰仍在使用的中间结果，总缓存预算仍生效。
- 缓存键保留 Size／Baseline／Full、尺寸确定性和百分比依赖；仅归一化对当前计算无效的约束。
- 利用结果的前序顺序计算溢出的父节点索引，移除逐节点哈希分配；简化盒信息发布及零位移处理。
- 增加 4／12／24／48 层 Flex 回归，检查换行几何、缩放、叶更新和工作量。拆分阶段同时修复 Debug／ASan 的 48 层栈溢出。

## 结果摘要

| 模式 | 可配对场景数 | 几何平均加速 | 场景范围 |
|---|---:|---:|---:|
| 首次布局 | 17 | 1.59× | 1.03–2.67× |
| 尺寸变化 | 17 | 2.24× | 1.14–28.97× |
| 叶内容更新 | 6 | 1.69× | 1.15–2.71× |

“几何平均”对每个场景等权；不是某个实际应用的总体加速。原来失败的深树不计入加速倍数。

最终采样的 40 组可配对计算中位数均下降（不含无变化缓存调用）。
尚未达到整体性能对齐：18 个首次布局场景仍全部慢于 Taffy，Flex 首次也仍慢于 Yoga。
嵌套 Flex 的尺寸变化已更快：384 叶为本库 76.06 µs、Taffy 154.15 µs、Yoga 479.67 µs。
这项收益来自在父容器宽度变化时复用宽度固定的子树；不能推广到全部 Flex 输入。

### 采样波动与复核

保留[初次完整采样](initial-after/summary.csv)及全部原始批次。
其中 `flex_content_100/leaf_edit` 出现 92.89→102.60 µs 的表观回退，
优化后两轮的中位数差异较大。针对该项将每批增至 1700 帧、9 批、前后版本交错跑 4 轮，
得到 79.79→57.90 µs（1.38×），全部 checksum 一致，详见[交错复核](flex-content-paired-check.json)。
最后整理了五处函数开头的换行，再次构建并完整采样；正文采用该最终二进制结果，
这项为 92.89→81.10 µs。两次重构后采样的计算逻辑相同，原始记录均保留。

上述波动表明本机墙钟数据不能被解读为稳定的百分比承诺，尤其不能将约 3% 的差异视为显著提升。
未设置 CPU affinity，未控制其他应用、系统调度或 CPU 频率；各轮范围和批次 p95 保留在原始 CSV。

## 验证与方法

- Release：377／377；Debug：377／377；ASan：376／376（ASan 配置关闭 examples，少一项 retained example）。三套均重放完整 Taffy 上游 6020 项和补充矩阵。
- Comparison Release：333／333，已将原来失败的深树加入三方几何 smoke。
- 本次优化后：18 个场景、159 组引擎／模式全部成功；重放 5,313,214 个节点矩形（含参考侧），本库／Yoga 与 Taffy 逐节点逐帧对照的最大绝对误差为 0.000757227px。容差为 0.01px + 相对 1e-6。
- 优化前使用改动开始时保存的 Release 二进制重新测试；优化后使用重构后的 Release。原始失败记录保留在 before/failures.json。
- 两轮，每轮 9 批；第二轮反转引擎顺序。小树每批 170 帧，大树 34 帧，17 个窗口尺寸。正式测试串行执行，期间没有并行构建或测试。
- 每批计时先除以帧数，再取 18 批的中位数；原始 CSV 的 p95 同样属于批次统计，不是逐帧尾延迟。
- 计时包含 edit／dirty、compute 和三个矩形读取；解析、树构建／销毁、预热不在计时内。输入与此前报告一致。
- 采用相同的合成文本度量，不包含真实文本塑形或绘制。只有 Flex 子集与 Yoga 比较。
- MSVC `/O2 /Ob2 /DNDEBUG /MD`；Rust opt-level=3、codegen-units=16；双方均关闭 LTO。使用默认深度、测量和缓存预算，没有绑定 CPU affinity。
- 本库发布平铺、根相对几何及 Grid 诊断；Taffy／Yoga 保留节点局部几何。结果形态是现有 API 的实际成本。
- unchanged/same 为亚微秒量级，并且均为零测量；保留原始数据，不据此排列引擎名次。

## 内存取舍

缓存移入节点并增加盒模型缓存后，MSVC x64 Release 的内部节点对象从 1344B 增为 1624B（+280B／节点）；同时移除了独立持久缓存哈希节点，并减少临时结果。分配探针统计的是布局窗口，排除了建树，不能据此宣称整个进程的内存占用下降。

384 叶合成文本的首次申请次数从 21,904 降至 17,157（−21.67%），
但累计申请字节增加 66.66%，布局窗口峰值存活字节增加 27.02%。
叶更新的申请次数减少 43.01%，窗口峰值减少约 1.36%；无变化仍为零申请。
DirectWrite 96 叶首次申请次数减少 20.96%，窗口峰值增加 24.72%。
[完整分配报告](allocations/README.md)包含 36 组配对、两种后端、两种失效策略、计数边界与复现命令。
