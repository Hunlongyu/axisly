# CSS 布局第二轮结构重构与三方复测（2026-09-30）

对比对象为当前 `css::LayoutTree`、上一轮优化最终版本、Taffy 0.14.0、Yoga 3.2.1。单位 µs，越小越好。优化前后在同一轮交替运行。

## 修改内容

- 节点目录改为连续哈希槽，保持节点地址稳定、全局唯一 ID、删除及跨树检查。
- 布局与测量缓存改为树级槽池；计算期间暂存，成功后通过链接提交，失败回滚。保留缓存条目和总预算限制。
- 尺寸查询和最终几何发布分离；测量叶的纯尺寸查询保留独立缓存，不重复建立完整结果。
- 子树几何使用共享结果；命中缓存只复制句柄，最终发布一次展开。纯平铺子节点使用连续存储，独占缓冲直接交给发布结果。平移逐步保留原有舍入和溢出检查。
- `Length` 从 32B 压至 8B；`Style` 1232→632B，内部节点 1624→1024B。数字和关键字不分配内存，calc 表达式共享带引用计数的存储。
- Flex 分行使用连续索引区间；冻结状态和约束偏差随工作项保存，移除逐行、逐轮临时数组。短数值函数的异常构造移出热点。
- 子节点追加改为几何扩容，修复每追加一个节点就 reserve(size+1) 的二次复制。现有 compute 基准排除建树，不把这项计入所列加速。
- 新回归覆盖节点存储生命周期、失败事务回滚、表达式所有权、缓存的深度预算、滚动条与 aspect-ratio 最大尺寸顺序，以及混合/平铺几何快照的生命周期。

合成文本及 DirectWrite 共 36 组配对 checksum 一致，每组 3 批×20 帧。
探针只统计当前线程布局窗口内的 C++ new/delete，排除建树、窗口前已持有的缓存、其他线程和系统内部申请。累计申请与窗口峰值均不等于整个进程的常驻内存；插桩耗时不用于三方性能结论。
槽池保留达到过的容量以便复用；节点删除或缓存失效不会立即归还全部槽容量，销毁 LayoutTree 时释放。
calc 的单个独立 Length 新增一份共享载荷分配，复制不重复分配；本轮 18 个计时场景不覆盖 calc 密集输入。公开函数接口保持，但 Length/Style 的对象布局改变，使用方必须重新编译。

## 验证与计时条件

- Release 383/383、Debug 383/383、ASan 382/382；三套包含完整 Taffy 上游 6020 项及补充矩阵。ASan 配置关闭 examples，少一项 example 测试。
- Comparison Release 339/339；安装后独立消费项目通过。
- 默认布局深度、测量和缓存预算保持；没有放宽几何容差或移除慢场景。
- 逻辑 CPU 4；全部引擎继承相同 affinity。两轮各 9 批，第二轮反转引擎次序，每批帧数为原基准的 3 倍，17 个窗口尺寸。正式采样期间没有并行构建或测试。
- MSVC /O2 /Ob2 /DNDEBUG /MD；Rust opt-level=3、codegen-units=16；双方均关闭 LTO。
- 中位数和 p95 均来自批次平均每帧耗时，并非逐帧尾延迟。未锁定 CPU 频率或排除其他系统进程；小幅差异应结合原始两轮范围解读。
- 计时包含 edit/dirty、compute 和三个矩形读取；排除解析、建树、销毁及完整几何导出。文本为相同合成度量，不含真实塑形或渲染。
- 本库发布平铺的根相对几何和 Grid 诊断；Taffy/Yoga 保留节点局部几何。现有 API 结果形态的成本保留在比较中。
- same 模式均零测量，亚微秒数据保留在 CSV，避免用计时噪声给引擎排名。

## 发现的回退与处理

初次完整采样中，flex_fixed_1000/resize 从 628.06µs 增至 688.47µs。共享分支结构给纯平铺树增加了一次结果数组构造。随后增加连续叶存储，并在独占时转移结果缓冲；保留共享子树的不可变快照。新增混合树移动、缓存重放、600 叶平铺树和快照隔离回归。正文全部采用这次修正后的重新构建与全量采样。
[初次完整采样](initial-run/summary.csv)、initial-source-provenance.json、initial-validated-source-sha256.json、initial-core.patch 和 initial-allocations/ 保留了修正前的来源与数据。
